# 광고 끝맺음 검토 및 콘티 수정 · 2026-10-27

## 잘못된 기존 결정

추가 A/B/C의 마지막에 메디큐브 원본 **2초의 제품 식별 컷**을 공통 배치했다. 원본 광고의 엔딩을 분석해 가져온 것이 아니며, 각 안의 훅을 회수할 대사와 결론 없이 제품 사진으로 끝났다. 이 결정을 폐기했다.

## 실제 원본의 마지막

확보한 36개 레퍼런스의 첫3초·마지막최대12초·끝0.4초전 및1.5초전 프레임을 분석하고, 마지막 스틸36장을 별도로 시각 검토했다. 모델 음성 전사와 영상 판독에 기초하며 사람의 전편 직접 청취로 표현하지 않는다. 비광고·광고 미확인 자료도 포함된다.

- 소유: 관리 결론 → 콜라보 증정품·한정수량 → 매장 앞 손에 든 제품 → 올영 구매 문구. 상품 사진만 단독으로 끝난 것이 아니다.
- 풍자: 사용 부위 설명 → 52초 제품을 들고 직접 추천 → 품절 경험·쟁이기 요청 → 57초 마지막 얼굴과 “지금”. 마지막에는 튜브가 보이지 않는다.
- 이경실: 제품 소개와 설명 이후 본인 체감 증언으로 마침. 이름을 부른 뒤 그 인물의 답으로 신뢰를 회수한다.
- 박원숙: 섭취 설명 → 검사 일화 → 기뻐하는 표정과 기사 자막. 명시적 구매 요청 없이 만족 결과로 끝난다.
- 조혜련: 직접 배를 보여주는 동작·말장난으로 체형 훅을 회수하는 원본과, 제품을 든 반응형 원본을 구분한다.
- 메디큐브: 패드 시연·사용 후 상태 → 제품과 “It's 10/10” 평가. 제품 단독 화면이지만 앞 시연과 평가가 연결된다.
- 한혜진 활용 광고: 제품 화면 위에 별도 나레이션이 품절·가격·구매 경로를 안내한다. 제품 화면이라는 이유로 CTA가 없다고 세지 않는다.
- POLA: 본인의 마지막 발언과 별개로 하단에 제품 안내 띠가 있다. 실제 버튼 클릭 가능 여부는 확인되지 않았다.

36개 마지막 화면: 인물 증언12 / 얼굴+제품6 / 손+제품6 / 제품단독3 / 시연3 / 반응3 / 기타3.
CTA: 구매8 / 제품안내2 / 명시적 요청 없음20 / 추천3 / 저장공유1 / 댓글1 / 매장방문1.
이 사용 빈도는 엔딩의 성과 인과관계가 아니다. 공유·저장은 영상 전체 반응이며 각 카드에 별도로 유지했다.

## 추가 3안 수정

- A15초: 얼굴 → 우리 닦기 → 제품 → 도포 → 본인 선택 → 얼굴로 돌아와 그 크림 확인 요청. 풍자의 추천 장면52초와 실제 마지막57초를 별도 컷으로 차용한다.
- B18초: 타고난 동안 통념 → 관리 고백 → 제품 → 도포 → 실사용 설명 → “타고난 줄 알았죠? 저도 관리해요”로 첫 질문을 회수. 이경실·박원숙의 인물 결론형을 참고한다.
- C16초: 나레이션 질문 → 제형 → 제품 → 사용 → 본인 한마디 → 김가연+제품 위에 나레이션으로 제품·사용법을 안내. 한혜진 활용 광고의 결말 전달 방식을 참고한다.

상단 고정 문구·하단 자막 위치·6컷 형식 유지. 원본 발언과 김가연 추가 촬영 제안을 구분한다. 타 인물·제품 사진은 구도 참고이며 실제 광고는 김가연과 우리 제품을 사용한다. 원본의 품절·할인·효능 주장을 새 광고에 자동으로 옮기지 않는다.

N1/N2 이름 테스트도 수정된 A본편으로 동기화했다. 두 안은 상단 첫 줄만 다르고 나머지6컷·하단문구·CTA는 동일하다. 기존4안은 보존했다.
