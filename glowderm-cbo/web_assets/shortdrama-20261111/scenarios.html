# 안 믿는다더니, 내 크림이 사라진다

글로우덤 멜라크림 · 모녀 생활극 · 시나리오 v1 · 2026-11-11

**40초 목표**(낭독 미실측). 9:16, 인물 2명·화장대 한 장소. 결과물은 영상화용 시작 이미지와 시나리오이며, 음성·영상 생성은 이번 단계에 포함하지 않는다.

## 줄거리
기미크림을 안 믿는다던 엄마가 딸의 크림을 몰래 쓰다 들킨다. 돌려달라는 딸에게는 새로 사라고 하고, 본인은 링크부터 요구한다.

## 인물·공간 고정
엄마 56세: 자연스러운 중년 피부·짧은 웨이브 갈색 단발·말린 장미색 카디건·아이보리 티. 딸 31세: 어깨 길이 검정 생머리·연한 파랑 셔츠·흰 티. 꿀빛 오크 화장대·원형 거울·크림색 도자기 램프·얇은 커튼이 있는 한국 아파트 침실.

## 연출
첫 1초부터 관객에게 크림을 보여준다. 엄마의 부정과 손에 들린 제품의 모순이 웃음의 출발점이다. 회상에서는 도포·제형·제품을 보여주고, 현재로 돌아와 튜브를 놓지 않는 행동으로 구매 욕구를 표현한다. 엔딩의 웃음 다음 바로 제품으로 끝낸다.

이번 허구 상황극의 생성 피부는 제품 효능을 입증하는 전후 사진으로 사용하지 않는다. 기미 위치와 피부 결은 도포 전후에도 유지한다. 이전 6요소 중 고소 보증·전문가·레이저·날짜 전후 비교는 생활극 흐름과 맞지 않아 제외했다. 변화 근거는 별도 확인된 자사 자료가 확보됐을 때 추가할 수 있으며 이번 생성 컷에서 임의로 만들지 않는다.

영상 제작 단계에서는 짧은 대사마다 인물을 교대하고, 손·튜브·볼 접사로 연결한다. 일반 일상 장면이므로 맨손을 사용하며 클리닉 장갑을 억지로 넣지 않는다. 생성 컷에 자막·가격·상단 배너·작업용 라벨은 넣지 않는다.

# 구박하던 며느리, 임신 소식에 만났더니…

480p 숏드라마 검토본. 가상 인물·가상 상황. 임신 소식은 재회의 계기이며, 크림과 인과관계가 없다. 피부 모습은 극중 연출이며 임상 전후 비교 자료가 아니다.

1. 시어머니: “며느리가 저러니 애가 안 생기지.” / 며느리: “어머님, 그런 말씀은 하지 마세요.”
2. 몇 달 뒤 전화. “어머니, 저 임신했어요. 시간 되실 때 뵈어요.”
3. 카페 재회. “너… 얼굴이 왜 이렇게 좋아졌니?”
4. “저도 이제 저 좀 챙기려고요. 기미 관리는 이걸로 해요.”
5. 크림을 바르는 회상. 제품 나레이션: “글로우덤 다크스팟 멜라크림. 핵심은 트라넥삼산 5%.”
6. “나도 하나 줘 봐.” / “어머님, 축하한다는 말은 아직 안 하셨어요.”
7. “그래… 축하한다. 미안하다.” / “링크는 보내드릴게요.”
8. 제품 컷. “글로우덤 멜라크림. 아래에서 제품 구성을 확인해 보세요.”
