키 차이가 한눈에 보이게
  1. 카메라 위치·높이·줌을 고정해요. 같은 옷·자리·자세로 맨발 또는 양말 상태와 착화 후를 촬영해요.
  2. 머리끝부터 발끝·바닥까지 담고, 전후 장면을 좌우로 붙여요. 머리 높이 기준선을 넣어 차이를 보여줘요.
  3. 바지 끌림은 같은 바지·같은 밑단 길이로 촬영해요. 비교 중에 허리나 밑단을 올리지 않아요.
  4. 수치 자막은 선택 제품의 공식 높이를 확인해 “신으면 +Ncm”로 넣어요. 예시 영상의 수치를 복사하지 않아요.
