2026-11-02 사용자 확정 · 정기 업무: 글로우덤 멜라크림·필링팩클렌저

## 이번 주 제작 목표 — 11/3 갱신

| 날짜 | 제작 목표 | 편수 |
|---|---|---|
| 11/3 화 | 시나리오 12로 A/B 제작 | 2 |
| 11/4 수 | 클렌저 시나리오 1개로 A/B 제작 | 2 |
| 11/6 금 | 멜라크림 1편 + 클렌저 1편 | 2 |
| 합계 | 사용자 확정 제작 목표 | **6** |

11/2 실습과 기존 작업 수정본은 6편에 더하지 않는다. 11/5는 검수·수정·업로드 준비 배정안이다. 클렌저·금요일의 구체적인 시나리오는 지정 시트에서 확정한다. 제작 목표와 실제 납품·집행 완료는 구분해서 기록한다.

## 하나의 기준으로 연결하기

**제품별 소구점 → 후킹 → 몸통 → 성분 설명 → CTA → 제작·업로드 → 테스트·리뷰 → 개선 제작.**

기획의 골격은 네 단계로 유지한다. 강한 후킹 요소·내용·시나리오는 **2주마다 ACIS를 다시 보거나 과거 장기 집행 소재에서 선택**한다. 장기 집행은 참고 소재를 고르는 근거이고, 우리 광고에서 성과가 났다는 뜻은 아니다.

시나리오 원문은 [콘텐츠기획팀_글로우덤시나리오](https://docs.google.com/spreadsheets/d/1sIyn3kYLMt9XAxaUpaixnO5H_Un8G5iz5AoCuJIrjJM/edit)에 계속 추가한다. 원본 대사·장면·참고 영상·캡처는 시트에서 관리하고, [운영 보드](index.html)는 배정·제작·업로드·성과·다음 개선 작업을 연결한다. 시트에 새 시나리오가 생기면 해당 탭 링크를 작업 카드에 추가한다.

## 네 단계의 역할

| 단계 | 기획에서 정할 것 | 편집에서 확인할 것 | 리뷰에서 볼 것 |
|---|---|---|---|
| 후킹 | 첫 화면, 첫 문장, 강한 시각 요소 | 첫 프레임에 고민이 읽히는가, 후킹과 다음 장면이 이어지는가 | 1~3초 유지율, 첫 이탈 구간 |
| 몸통 | 고민·상황 → 사용·시연 → 변화의 흐름 | 설명하는 말과 보여주는 장면이 맞는가, 반복·장면 나열이 없는가 | 후킹 이후 유지율, 시연 전후 이탈 |
| 성분 설명 | 우리 제품의 핵심 성분·함량·원리와 선택 이유 | 제품이 맞는가, 성분을 나열하지 않고 앞의 시연과 연결하는가 | 성분 구간 진입·이탈, 설명 길이 |
| CTA | 제품·구성과 다음 행동 | 마지막 화면과 링크의 제품·혜택이 일치하는가 | 링크 클릭·방문·구매·광고비 대비 매출 |

성분 설명은 몸통 속 한 번의 제품명 노출로 대체하지 않는다. 길이와 구간의 초수는 실제 녹음 뒤 맞춘다. 내레이션은 통문단으로 먼저 만들고 컷을 넘어 이어지게 편집한다. 첫날 J01만 후킹·몸통의 10초 실습으로 운영하며 신규 광고 실적에서 제외한다.

## 제품별 소구 포인트

| 제품 | 중심 소구 | 몸통에서 보여줄 것 | 성분 설명 | 마무리 |
|---|---|---|---|---|
| 멜라크림 | 기미 고민, 도포·전후 변화, 약국 신뢰 | 고민 부위 접사 → 제형·도포·같은 부위 비교 | 트라넥삼산(TXA) 5%를 중심으로, 필요 시 TXA·코직산 → 멜라제로V2 → 살리실릭애씨드의 신호·분해·배출 설명 | 실제 제품과 현재 판매 구성 확인 |
| 필링팩클렌저 | 화이트헤드·화잘먹·오돌토돌·각질·흑꿈치 다섯 축 중 하나 | 해당 고민 → 롤링·고마쥬 → 물·거품 세정 → 피부결. 흑꿈치는 팔꿈치 접사와 각질·세정 루틴으로 연결 | BHA·LHA → 셀룰로오스 고마쥬 → TXA의 CLEANSE·POLISH·GLOW. 3in1·1분 사용 흐름과 연결 | 실제 클렌저와 현재 구성 확인 |

멜라크림의 기능성·시험·약국 진열, 클렌저의 사용법·저자극·세트 루틴은 보조 소구다. 한 편에 전부 넣지 않고 중심 소구 하나와 필요한 증거를 고른다. 오래된 가격·리뷰 수·할인율을 복사하지 않는다. 제작 연출을 실제 고객의 결과나 임상 자료로 기록하지 않는다.

기존 멜라크림 강한 후킹 장치: 비포 먼저·도포 소거·2주 날짜 카드·보증형 문장·전문가 해설·레이저 비교. 시나리오별 적용과 제외 이유를 남긴다. S20은 기존에 썰·시연 중심으로 별도 결정한 예외다. 10/22 이후 결정과 개별 지시가 8/28 문서의 일반 선호보다 우선한다.

## 격주 기획 리프레시

이번 운영 주기: **11/2~11/15**, 다음 검토: **11/16**, 이후 **11/30**. 이는 기획 검토 일정이며 자동 수집 작업을 새로 설치한 것은 아니다.

1. ACIS의 제품·고민이 맞는 소재를 읽고, 신규 소재와 과거 장기 집행 소재를 비교한다.
2. 원본 링크·캡처·광고 ID·집행일수·관측일을 남긴다. 집행일수는 조회 시점의 기록을 쓰고, 종료일이나 관측일 차이로 다시 추정하지 않는다.
3. 후킹·몸통·성분·CTA로 분해해 가져올 요소를 적는다. 참고 소재의 내용과 우리 추가 아이디어를 구분한다.
4. 우리 소구점으로 연결하고 시나리오와 캡처를 위 시트에 추가한다.
5. A/B는 하나의 변수만 다르게 만든다. 공통 몸통·성분·CTA·길이·목소리·음악·타깃·랜딩은 비교 목적에 맞게 고정한다.
6. 성과 리뷰에서 유지할 것과 바꿀 것 한 가지를 정해 다음 기획에 반영한다. 새로운 주기가 와도 잘되는 소재를 날짜만으로 교체하지 않는다.

## 제작·업로드·성과·개선의 연결

| 단계 | 책임 | 완료 증거 | 다음 행동 |
|---|---|---|---|
| 기획·소스 준비 | 제현 | 시트 탭·A/B 변수·사용 소스·음원·납기 | 편집자 배정 |
| 편집·수정 | 편집자 | A/B MP4·프로젝트·소스 목록·제작 메모 | 제현에게 전달 |
| 검수 | 제현 + 편집자 | 전체 재생·소리·자막·제품·4단계·차이점 확인, 수정본 링크 | 확정본 기록 |
| 업로드 | 제현 | 확정 파일·광고 ID·실제 집행 시작일·랜딩·제품별 캠페인 연결 | 성과 추적 |
| 성과 리뷰 | 제현 | 같은 기간의 노출·유지율·클릭·구매·지출·매출 + 해석 | 유지·개선·보류 결정 |
| 개선 제작 | 제현 기획 / 편집자 제작 | 기준 영상·이전 버전·바꿀 단계·변수 한 개·예상 개선·다음 기한 | 새 버전 또는 새 A/B로 재테스트 |

제작 목표는 **하루 1시나리오 × A/B 2편**이다. 첫 3일 초안 17시, 정상 운영 초안 15시·수정본 18시를 목표로 한다. 기존 v2·v3 수정을 신규 편수로 중복 집계하지 않는다. 시나리오 수정과 함께 A/B 변수를 바꿨다면 이전 광고와의 순수 비교로 읽지 않는다.

업로드는 **제품별 기존 테스트 CBO의 기존 세트에 새 광고 추가**가 현재 구조다. 과거 ‘매일 ABO 두 세트’ 배정안을 사용하지 않는다. 실제 등록·집행이 확인되기 전에는 예정일을 완료일로 바꾸지 않는다.

성과 확인은 매일 진행하고, 실제 집행 시작 후 3일차에 후킹·유지·클릭을 리뷰하고 6일차에 구매·매출을 함께 검토한다. 노출 1,000 미만 등 비교할 데이터가 적으면 판단을 보류한다. CBO는 소재별 노출이 균등하지 않으므로 이를 무작위 A/B 실험으로 표현하지 않는다. 현재 자동 중단 기준은 기존 성과 페이지·가드 정본을 따르며, 이 보드가 광고를 자동 중단하거나 켜지 않는다.

개선 기록: **관측 사실 → 원인 가설 → 유지할 것 → 바꿀 단계·변수 → 새 버전·다음 확인일**. 초반 유지율이 높다는 이유만으로 구매 승자로 확정하지 않는다.

## 성과 부진 시 +α 밈형 테스트

기본 소재의 성과가 부진할 때 **필재 TTS형·애니메이션형 등 밈형 콘텐츠를 추가 투입**한다. 제품별 핵심 소구와 후킹 → 몸통 → 성분 설명 → CTA의 연결은 유지하고, 말투·화자·시각 연출 등 표현 방식을 바꿔 테스트한다.

**이번 주 기본 제작 목표 6편에 더해 진행하는 추가 테스트**다. 상시 고정 물량으로 배정하지 않으며, 성과 리뷰에서 적용할 제품·소구·형식과 제작 편수·일정을 정한다.

리뷰에 부진한 지표와 바꿀 형식을 적고, 밈형 시나리오도 지정 시트에 추가해 제작·업로드·성과를 연결한다. 같은 제품·비교 가능한 기간의 기존 소재와 결과를 살펴 유지·개선·보류를 결정한다.

## 제품별 대소구·중소구·소소구와 강한 후킹

기존 소구 도감의 분류를 사용한다. 대소구는 영상 전체의 큰 틀, 중소구는 설득 재료, 소소구는 강한 한 줄 표현이다. 자막 위치·유지 시간은 별도 화면 배치다.

### 멜라크림

| 구분 | 선택할 내용 |

| 대소구 | 전문가·개발자 설명 / 경험담·주변 반응 / 도포 시연 / 레이저 비교 중 이번 편의 큰 틀 하나 |

| 소소구 | 레이저 · 바르는 레이저 / 기미 삭제 · 2주 삭제 / 2주 만에 변화 / 안 없어지면 고소하세요 / 피부과 다니냐 / 트라넥삼산 5% |
